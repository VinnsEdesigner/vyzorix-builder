# Base-image digests.
#
# Each line pins a base image's tag to its digest, so the same source builds the
# same bytes on two machines. tooling_embed.py embeds this file into the binary;
# apply_image_pins rewrites every `FROM <ref>` to `FROM <ref>@<digest>`.
#
# An image with no line here stays a floating tag — a documented exception.
# `--pull` refreshes a base image deliberately.
#
# Refresh a pin with:
#   docker buildx imagetools inspect <image>:<tag> --format '{{.Manifest.Digest}}'
